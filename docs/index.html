Named account profiles

Keep your default Codex window open normally. This manager lists and launches additional instances with their own logins, sessions, settings, and databases.

02

Let a worker consult the main instance's guidance and memories. Sharing is off by default for new profiles. It shares reference context, not live conversations or account credentials.

GET STARTED

Download. Name. Launch.

You need Windows 11 and the Codex desktop app. No extra runtime is required.

  1. 1

    Install the manager

    Download and extract the ZIP. Open the Codex-Instance-Manager folder and run Install.cmd. Installation is per-user.

  2. 2

    Create your instance

    Open the manager desktop shortcut. Choose New instance, give it a name, and save it to create a desktop shortcut.

  3. 3

    Save and open Codex

    Choose Open Codex. Sign into the intended account on first use. Optionally copy main local projects and chats while that instance is closed.

A FEW THINGS TO KNOW

Before you launch.

Is this an official OpenAI tool?

No. It is an independent community project by artizandevs, not affiliated with or endorsed by OpenAI. It launches the desktop app you already have installed.

How reliable is running separate desktop accounts?

This release uses an undocumented desktop profile override found in Codex package 26.1002.7124.0. An app update could change it. Profile isolation and snapshot-import checks are automated; simultaneous sign-ins and browser callbacks still need wider live testing. Complete first-time sign-ins one at a time and check each window's account.

Will I see my main chats and projects?

Use Copy main projects & chats to import independent local snapshots. Repeating it adds new chats without overwriting existing copies. Cloud ChatGPT chats, open tabs, and live synchronization are not available. Project folders point to the same files on disk.

What happens to my existing accounts and data?

Your default window stays outside the manager. Updates preserve worker profiles and retire the old Main launcher entry without changing its Codex data. Removing an instance removes its manager entry and keeps its folders. Updates also preserve any worktrees from older versions. The launcher does not copy account credentials between profiles.

What does shared memory actually share?

It tells a worker to consult the main instance's guidance and memory files. Relevant content may enter that worker's model context. This is an instruction rule, not a Windows access-control boundary. It does not combine chats or automatically merge new worker memories.

Does the launcher submit prompts or collect telemetry?

It opens account windows and imports local snapshots without submitting prompts. This launcher includes no telemetry or cloud-sync service. Codex is a separate application with its own settings and behavior.
